# Journal — 7 juillet 2026

## Incident : régression de version en production (résolu)

Le 06/07 à 15:20 UTC, trois minutes après le build de la release v0.6.66, la
production a été basculée par erreur sur le tag **0.6.61** (`roll-image.sh`
avec un tag erroné), soit quatre versions en arrière : agent Satellite absent,
dialogue consultatif par sujet absent, et bug du cache sémantique pré-0.6.63
réactivé (questions météo servies par un refus mis en cache).

Diagnostic par l'historique des ReplicaSets
(`kubectl get rs -l app=api --sort-by=.metadata.creationTimestamp`). Constat
associé : l'Application ArgoCD `opencacao` n'existe plus sur le cluster —
`deploy/scripts/roll-image.sh` est l'**unique** chemin de déploiement ; après
chaque release, vérifier le tag réellement déployé.

Résolution le 07/07 : redéploiement `roll-image.sh 0.6.66`, non-régression
complète (santé, garde-fous, météo réelle, Satellite, web).

Avant : premier signal visible = premier token (15-26 s de silence). Après :
statut en ~0,3 s. Les événements pèsent ~60 octets : seule la latence réseau
compte, donc le gain tient sur mobile (premier signal ≈ 0,3-0,5 s en 4G,
≈ 0,7-0,9 s en 3G) — silence perçu divisé par ×15 à ×70 selon le réseau.
